# Collage Layout Algorithm v2 — 重要性感知的行分组与紧凑/长图自动切换

## 背景

现有的 `computeRowPack` 算法以 `count ≤ 7` 为硬边界决定紧凑/延伸两种模式。7 张以内的照片固定画布 390×500，超过 7 张则画布随内容延伸。但这种划分没有考虑照片重要度、横竖比例、以及实际排版的可视效果。

目标：用统一的贪心分组替代硬编码计数阈值，根据照片重要度决定每行张数，并根据总行数决定是否延长为长图。

## 行分组算法（统一逻辑，对所有照片生效）

1. 照片按 `importance` 降序排列
2. 贪心跳行：
   - 从最重要开始，逐张加入当前行
   - **每行容量**：若当前行已有/将有的照片中 `importance > 0.7`，则该行最多 2 张；否则最多 3 张
   - **宽度约束**：`testSum * rowHeightMin > canvasWidth * rowFillThreshold` 仍然作为辅助约束（宽图自动减少每行张数）
   - 当行容量或宽度约束达到上限时，开启新行

## 紧凑 vs 长图切换

| 条件 | 模式 | 行为 |
|------|------|------|
| 总行数 ≤ 3 | 紧凑 | 固定画布 390×500，行高从画布高度反推（铺满 + 垂直剩余空间再分配） |
| 总行数 > 3 | 长图 | 画布向下延伸，行高由照片 aspectRatio 的自然比例决定 |

紧凑模式的铺满逻辑（行高计算 + 宽度溢出缩放 + 垂直剩余再分配）保持现有实现不变；长图模式的行高计算保持现有的非紧凑逻辑不变。

## 气泡（Caption）放置

保持两阶段放置不变：
- 第一阶段：放置所有照片，收集全部照片位置
- 第二阶段：为每张照片放置 caption 气泡，以所有照片位置为障碍物（排除自身，允许略微重叠）

气泡候选位置分两组（外部 + 角落重叠），`boxesCollide` 的 gap 参数为 0（候选位置已自带间距）。

## 参数常量

| 参数 | 值 | 说明 |
|------|----|------|
| `canvasWidth` | 390 | 画布宽度 |
| `canvasHeightMin` | 500 | 紧凑模式固定高度 |
| `importanceVipThreshold` | 0.7 | 重要度高于此行最多 2 张 |
| `maxNormalPerRow` | 3 | 正常照片每行最多张数 |
| `maxCompactRows` | 3 | 紧凑模式最大行数 |
| `overlap` | 6 | 气泡重叠照片的距离（px） |

## 文件变更

- `frontend/src/lib/templates/layout/row-pack.ts` — 核心算法修改
  - 移除 `compact = count <= 7` 判断
  - 统一贪心分组逻辑（重要性感知）
  - 紧凑/长图由行数决定
  - 其余（气泡放置、行高计算、垂直再分配）保持不变

无需修改 template 组件、API 或数据结构。
